# Numerator

Generator nomor urut otomatis untuk kebutuhan percetakan, invoice, tiket, kupon, nota, dan dokumen bernomor lainnya.

![Preview](https://cdn.discordapp.com/attachments/404590674370101248/1528033623268135084/image.png?ex=6a5cd3b5&is=6a5b8235&hm=8141bd2af7bf4d719f051683c72cbf9339e301eebab11eb875cddf0d772e14ac)

---

## ✨ Fitur

- Generate nomor otomatis
- Multi kolom / titik nomor
- Custom angka awal
- Step / increment nomor
- Padding digit (`001`, `0001`, dst.)
- Prefix & suffix nomor
- Preview langsung
- Copy hasil format raw
- Print & Save PDF
- Ringan tanpa framework
- Tersedia mode dark & light

## 📦 Instalasi

Clone repository:

```bash
git clone https://github.com/kangarii/numerator.git
```

Masuk ke folder project:

```bash
cd numerator
```

Jalankan menggunakan browser:

```bash
index.html
```

Atau gunakan **Live Server** di VS Code.

---

## 🛠️ Cara Penggunaan

### 1. Isi konfigurasi nomor

| Field | Keterangan |
|---|---|
| Titik Nomor | Jumlah kolom nomor |
| Angka Awal | Nomor pertama |
| Jumlah Lembar | Total baris nomor |
| Step | Kelipatan nomor |
| Padding | Jumlah digit |
| Prefix | Teks sebelum nomor |
| Suffix | Teks setelah nomor |

---

### 2. Klik Generate

Hasil nomor akan muncul otomatis.

Contoh output:

```txt
INV-0001
INV-0002
INV-0003
```

---

### 3. Cetak atau Export PDF

Gunakan tombol:

- Print
- Save PDF
- Download .txt
